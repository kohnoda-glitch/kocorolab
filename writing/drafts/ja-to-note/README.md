# note へ、2020年10月8日の日付で入れる

普通の投稿画面では過去日付は選べません。この XML をインポートします。

ファイル: `2020-10-08-sdgs-goal-1-note-import.xml`

Mac に保存するなら、GitHub でこのファイルを開いて Download してください。

1. note にログインする  
2. 自分のアイコン → **自分の記事**  
3. 右上の **インポート**  
4. **WordPress（WXR）** を選ぶ  
5. この XML をアップロードする  
6. 完了メールが来るまで待つ  
7. 下書きに「SDGs 目標１絶対的貧困０達成チャレンジin Africa」が入っているか見る  
8. 公開日が **2020年10月8日** か確認する  
9. 写真を見て、問題なければ **すぐ公開** する  

下書き保存だけして閉じると、日付が今日にずれることがあります。直したら公開まで一気にやってください。

2020年の記事は note の新着にはほとんど出ません。日付を残すための移動です。

プロフィール写真は 320×320 です。日本語の図（IPCC、DAC、予算、地図）は元の日本語のままです。
