# 取り込みファイルを Mac に入れる

**2026年9月5日 15:18 に失敗したファイルは使わないでください。**
あの XML には note が必須とする `wfw` 名前空間が無く、
「エクスポート元のWordPressで生成されたファイルではない可能性があります」と拒否されました。
**下の新しい zip** を保存し直してください。

1. このリンクを **右クリック** する  
   https://github.com/kohnoda-glitch/kocorolab/raw/cursor/note-medium-writing-4caf/writing/drafts/ja-to-note/note-import.zip
2. **名前を付けてリンク先を保存**（Save link as）を押す
3. 保存先は「ダウンロード」のままでよい
4. 保存した `note-import.zip` をダブルクリックする
5. 出てきた `note-import.xml` を、note の「自分の記事 → インポート → WordPress」に入れる

Chrome で XML を左クリックすると、画面に文字が出るだけで保存されません。zip を右クリックしてください。

# 取り込んだあと

日付が **2020年10月8日** になっているか見てください。
図が無いときは、新しく記事を作らず、**今の下書き** に絵を貼ってください。
新しい記事を作ると日付が今日になります。

下書きのまま長く置いて保存だけすると、日付が今日に戻ることがあります。
中身を確認したら、すぐ公開してください。

# 図が出ないとき

文字だけ貼ると、図1・図2は見出しだけ残って絵が出ません。
**絵が見えるページからコピー**してください。

1. このページを開く  
   https://htmlpreview.github.io/?https://github.com/kohnoda-glitch/kocorolab/blob/cursor/note-medium-writing-4caf/writing/drafts/ja-to-note/OPEN-IN-BROWSER.html
2. グラフと写真が見えるまで待つ
3. 黄色い枠の**下**を、いちばん下までマウスでなぞって選ぶ
4. `⌘C` でコピー
5. note の下書きを開く
6. 図が出ていない本文を消す（タイトルはそのままでよい）
7. 本文をクリックして `⌘V`

グラフが見えたら成功です。
