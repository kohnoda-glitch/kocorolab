# note に入れる（いちばんやさしい手順）

やることは2つだけです。

1. 日本語を note に入れる（日付は 2020年10月8日）
2. あとで Medium の日本語を、同じ記事のまま英語に書き換える

---

## 1. 取り込み用ファイルを Mac に置く

1. Safari か Chrome で、このページを開く  
   https://github.com/kohnoda-glitch/kocorolab/blob/cursor/note-medium-writing-4caf/writing/drafts/ja-to-note/2020-10-08-sdgs-goal-1-note-import.xml
2. 右上の **Download raw file**（下向き矢印）を押す
3. ダウンロードフォルダに  
   `2020-10-08-sdgs-goal-1-note-import.xml`  
   が入れば成功です

中身を開いて編集する必要はありません。

---

## 2. note に取り込む

1. https://note.com/ を開いてログインする
2. 右上の自分の顔（またはアイコン）をクリックする
3. **自分の記事** を開く
4. 画面の右上あたりにある **インポート** を押す
5. **WordPress** と書いてある方を選んで進む
6. さっきダウンロードした XML ファイルを選ぶ
7. 取り込み開始を押す
8. メールが来るまで待つ（数分かかることがあります）

いきなり公開はされません。下書きとして入ります。

---

## 3. 下書きを確認して公開する

1. もう一度 **自分の記事** を開く
2. 「SDGs 目標１絶対的貧困０達成チャレンジin Africa」という下書きがある
3. 開いて、写真と図表が出ているか見る
4. 日付が **2020年10月8日** になっているか見る
5. よければ **公開** を押す

注意: 直したあと、下書き保存だけして閉じると、日付が今日に変わることがあります。確認したら、その場で公開までやってください。

2020年の記事なので、フォロワーの「新着」にはほとんど出ません。日付を残すための移動です。

---

## 4. あとで Medium の日本語を英語にする

ここは **新しい記事を作らない** でください。https://medium.com/new は使いません。

1. Medium にログインする
2. 自分のアイコン → **Stories**（自分の記事一覧）
3. 2020年の日本語「SDGs 目標１…」を開く
4. **Edit story**（編集）を押す
5. タイトルを英語にする  
   `SDGs Goal 1: A challenge to reach zero extreme poverty in Africa`
6. 日本語の本文を全部消す
7. このページを開く  
   https://htmlpreview.github.io/?https://github.com/kohnoda-glitch/kocorolab/blob/cursor/note-medium-writing-4caf/writing/drafts/en-from-medium/OPEN-IN-BROWSER-sdgs-goal-1.html
8. 写真と英文をマウスでなぞって選び、`⌘C` でコピーする
9. Medium の本文（タイトルの下）をクリックして `⌘V` で貼る
10. 写真と見出しが見えたら保存する

このやり方なら、Medium の公開日は **2020年10月8日のまま** です。

note の図は、このリポジトリの中にあるので、Medium を英語にしても消えません。
