# 図が出ないとき

文字だけ貼ると、図1・図2は見出しだけ残って絵が出ません。
**絵が見えるページからコピー**してください。

1. このページを開く  
   https://htmlpreview.github.io/?https://github.com/kohnoda-glitch/kocorolab/blob/cursor/note-medium-writing-4caf/writing/drafts/ja-to-note/OPEN-IN-BROWSER.html
2. グラフと写真が見えるまで待つ
3. 黄色い枠の**下**を、いちばん下までマウスでなぞって選ぶ
4. `⌘C` でコピー
5. note の下書きを開く
6. 図が出ていない本文を消す（タイトルはそのままでよい）
7. 本文をクリックして `⌘V`

グラフが見えたら成功です。
