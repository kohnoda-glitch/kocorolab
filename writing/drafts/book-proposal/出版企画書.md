# 『昭和というロストテクノロジー』

**仕事のコミュニケーションコストは下げろ。人間のコミュニケーションコストは上げろ。**

## 2. 一枚で言うと

AIが、いわゆる「頭のよさ」を安くした。残るのは、身体、対人、現場で使う言葉といった、包括的な能力である。感情もそこに含まれるが、本の看板にはしない。多重知能は地図のひとつである。

### 書店で手に取る理由

- 仕事のコストは下げろ。人間のコストは上げろ。
- ChatGPTに聞くな。会いに行け。
- 昭和の全部を戻せ、ではない。捨てたはずの会う・雑談・世話・失敗の共有を、設計し直せ。
- STEMの先に残るのは、頭のよさ以外の能力である。

## 3. なぜ今か

生成AIは、資料・翻訳・議事録・コードを圧縮した。圧縮されないのは、身体で感じ、相手の状態を読み、言葉にして、関係を整え、合意に至ることである。学校では特別活動がまさにその訓練場である。家庭ではSTEM教育の親が、知識は足りている、足りないのは人間側だ、と気づき始めている。経営では、リモートとAIで仕事は回るが、人が離れ、現場の空気が読めない、という声が増えている。

身体、人と場、内面。こうした力は、経営教育の議論でも長く言われてきた。教育学でも、エリート教育の見直しでも、以前から出ている。特定の大学や国際機関の名前を並べれば新しく見えるが、新しさはそこではない。本書は、その再発見を繰り返さない。書くのは、AIが論理と知識を安くしたあとに、日本の家庭・学校・職場で、どの力をどう育てるかである。

この本は、メンタルヘルスの診断書ではない。学びと現場の設計の本である。

## 4. 読者

3層を同時に取る。中心は、親でもある大人である。

- STEM教育に関心のある親——知識は与えた。次に何を育てるか。
- 教師・学校関係者——特別活動・学級経営・探究。人と合意の作り方。
- 経営者・マネジャー——AI導入後に残る、人と現場のコミュニケーション。

若手には「昭和」という言葉のアレルギーがある。だから昭和は入口のコピーに使い、本文は包括的な能力で読ませる。タイトルは第一案以外でもよい。中身は変えない。

## 5. 中心概念

3名、ないし4名をつなぐのは、ひとつの理論の解説書ではない。頭のよさ以外の、包括的な能力である。多重知能は、その代表的な整理のひとつにすぎない。身体、対人、内面、言語。感情もそこに入る。IQやSTEMで測る力は、その一部でしかない。

顔ぶれは、その現場にいる。飯田は身体とものづくり（身体性ロボット・人工知能）。猪原は人と集団で決めること（合意形成・特別活動）。野田は認知科学と学びの設計。松岡は言語と現場の学び（RLE、子どもの英語教育）。

### 現場で使う地図

- 身体を読む——空腹、疲労、呼吸。頭の前にある。
- 場を読む——表情、空気、期待。一人では完結しない。
- 言葉にする——攻撃でも沈黙でもなく、共有できる形にする。
- 余白をつくる——衝動と行動のあいだに、選択肢を置く。
- 共に決める——違う価値観のまま、合意に乗せる。

### 5つの層

- 身体——心拍、呼吸、空腹、疲労。AIにはない出発点。
- 予測——予測と現実のずれ。驚きと好奇心。STEM学習の原動力。
- 意味——身体信号の解釈。データに価値を与える評価機能。
- 関係——表情、態度、期待、共感。ものづくりとチームに不可欠。
- 集団・社会——同調、制度、合意形成。特別活動と社会実装。

## 6. 章構成

序章と5章と終章。見出しは、問いと現場の言葉にする。章の担当は、これから組む。第3章を誰が書くかは、いまは決めない。

### 序章　捨ててしまったのは、会うことである

- なぜ「プログラミングができる子ども」ほど、AI時代に不安を感じるのか
- 仕事は速くなった。人が動かない。
- 会うことを、設計し直す

### 第1章　頭がいい人ほど、先に折れる

- ChatGPTに聞くな。会いに行け
- データは手段を選ぶ。何を大切にするかは、人が決める
- 正しいことが、人を動かさない理由

### 第2章　AIは、お腹が空かない

- ロボット研究者が、胃腸を見る理由
- 画面の前の論理が、こぼしているもの
- 予測が外れたとき、人は学び始める

### 第3章　0.5秒の余白をつくる

- 空腹を、性格だと思わない
- 衝動と行動のあいだに、選択肢を置く
- 沈黙と爆発は、同じ罠の両側である

### 第4章　リーダーの一声で、場の頭が悪くなる

- 「何でも言っていい」は、安全ではない
- 会う、雑談、世話、失敗の共有
- 場は、設計できる

### 第5章　正しいことを言っても、人は動かない

- 特別活動は、日本がすでに持っている訓練場である
- SNSは、理性を手放させる
- 対立の奥にある恐怖・屈辱・意地

### 終章　仕事のコストは下げろ。人間のコストは上げろ。

- 親が先に、自分の身体を読む
- 学校は、共に決める場をつくる
- 経営は、会いに行く

> 各章末に、短い実践を1つ置く（身体の天気予報、言葉の翻訳、驚きノート、場の地図、対話の問い）。理論だけで終わらせない。
